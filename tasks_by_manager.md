# Tasks by Website Manager (`tasks_by_manager.md`)

> **Role & Purpose**:  
> This file tracks pending data integrations, UI-backend contract gaps, and web-research tasks generated by the **Website Manager**.  
> Whenever a new UI element is created without an existing backend field in the data files or TypeScript schemas, a task must be logged here immediately, and the UI element must display `⚠️ (no source in data)` until resolved.

---

## 📋 Task Entry Template

When logging a new task, follow this standard structure:

```markdown
### [TASK-XXX] <Concise Title>
- **Category**: [Listings: Food | Sleep | Things | Shop | Quizzes | Results | Detail View | Savvy]
- **UI Component**: `<Path to Component>` (e.g. `src/components/finder/stay/AmenitiesSection.tsx`)
- **Missing Backend Field**: `<PropertyName>` in `<Path to Type>` (e.g. `hasHighSpeedWifi?: boolean` in `src/listings/types.ts`)
- **Required Data Files**: `<Path to listings>` (e.g. `src/listings/sleep/marrakech.sleep.ts`)
- **Web Search Query**: `"<Exact search query to find authentic facts>"`
- **Fallback Action**: If no real info exists online, apply the "no-color" neutral unconfirmed state.
- **Status**: [ ] Pending | [-] In Progress | [x] Completed
```

2. **Execute Web Search**: Conduct web search for authentic ground-truth information.
3. **Update Backend**: Add field to `src/listings/types.ts` and fill in accurate values across `src/listings/[category]/*.ts`.
4. **Remove Warning Marker**: Remove `⚠️ (no source in data)` tag from the UI component and bind the clean backend property.
5. **Mark Done**: Change `[ ]` to `[x]` in this backlog.
